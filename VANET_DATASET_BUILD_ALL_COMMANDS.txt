=========
1. These commands assume the project root is:
   $HOME/Documents/VANET_Project/FINAL_VANET_1000x1000

4. The exact project-specific MOVE export command/script was not available in the saved project information.

STEP 9 — OPTIONAL: BATCH-VALIDATE ALL SUMO CONFIG FILES
===============================================================================

for cfg in 02_SUMO/*.sumocfg
do
    echo "RUNNING: $cfg"
    sumo -c "$cfg" --no-step-log true --duration-log.disable true
    if [ $? -ne 0 ]; then
        echo "FAILED: $cfg"
        break
    fi
done

-------------------------------------------------------------------------------
MOVE GUI / EXPORT NOTE
-------------------------------------------------------------------------------

The project used the SUMO -> MOVE -> NS-2 mobility workflow.

The exact local MOVE installation/export command was not preserved in the
available project information, so no command is invented here.

If MOVE is installed as an executable, try:

move

or, from the MOVE installation directory:

./move

Inside MOVE:
1. Import/open the SUMO network and route/configuration.
2. Generate/run the mobility scenario.
3. Export mobility for NS-2.
4. Save the output in 03_MOVE/ using the project naming pattern.

After export, verify:

find 03_MOVE -maxdepth 1 -type f -name "mobility_*.tcl" | wc -l

python3 - <<'PY'
import pandas as pd
from pathlib import Path

p = Path("06_RESULTS/final_qos_expanded_9720.csv")

if not p.exists():
    raise FileNotFoundError(p)

df = pd.read_csv(p)

print("=" * 80)
print("FINAL RAW QoS DATASET AUDIT")
print("=" * 80)
print("File:", p)
print("Shape:", df.shape)
print("Columns:", len(df.columns))

if "Protocol" in df.columns:
    print("\nProtocol counts:")
    print(df["Protocol"].value_counts())

group_cols = [
    "Simulation_Seed",
    "Retry_Round",
    "Triplet_Attempt",
    "Nodes",
    "Speed_kmh",
    "Flows",
    "Packet_Rate_pps",
    "Mobility_Seed",
]

missing = [c for c in group_cols if c not in df.columns]
print("\nMissing grouping columns:", missing)

if not missing:
    sizes = df.groupby(group_cols, dropna=False).size()
    print("Unique comparison groups:", len(sizes))
    print("Rows per group:")
    print(sizes.value_counts().sort_index())

print("\nDuplicate full rows:", df.duplicated().sum())
print("=" * 80)
PY
